# Array in C

Practice programs for one-dimensional arrays in C, written as coursework during my
BS Software Engineering at COMSATS University Abbottabad.

Covered exercises: largest and second-largest element, index of the maximum value,
sorting, reversing, palindrome check, occurrence counting, common/different elements,
and sums of all / even / odd numbers. Each `.c` file is a standalone program —
compile with `gcc "Reverse Array .c" -o rev && ./rev`.
